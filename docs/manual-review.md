# 人工复审与正式入账

人工复审已接入网页和 MySQL。它与普通「已核对 / 需补材料」备注分开：备注用于跟进；正式复审需要选择决定、填写复审人和原因、预览差异，并明确确认提交。

## 操作流程

1. 打开任务，点击页面上方「开始复核」，或费用行右侧「复核并入账」。复核窗口展示原始观察、待复核原因和原件下载入口；需要逐字段查看原文依据时，可使用费用行的「查看依据」。
2. 也可从详情下方的「正式复审 / 修正入账」进入同一窗口。任务已绑定账本时不能换账本；数据库接入以前的历史任务可明确选择一个账本，第一次正式提交后固定归属。
3. 选择处理方式。确认新增时勾选独立费用确认；修改或重复时选择明确的目标旧账，同名行需按金额、编号和记录 ID 区分。
4. 新增或修改时修正费用、金额、币种、日期、交易双方、数量及单价等字段，明确付款方和收款方。应收 / 应付按所选账本公司的角色计算。金额使用普通十进制文本输入，无需千分位逗号；未知的非必要字段可留空。
5. 填写复审人姓名及解决原来问题的依据，点击「校验并预览决定」。检查旧值 → 新值、金额、方向、目标和账本版本。
6. 勾选原件与变更确认，再点击「确认提交正式复审」。成功后费用表显示人工决定及正式值，待复核计数减少。可在详情查看原始事实与正式决定，下载复审记录及当前有效账本。

| 决定 | 结果 |
|---|---|
| 确认新增 | 生成新的正式记录，不能覆盖旧记录，也不复制旧账的 ERP 扩展字段 |
| 修改旧账 | 只修改明确提交的字段，保留原记录 ID、未改字段和未知扩展数据 |
| 确认重复 | 绑定已存在的目标记录，原有业务字段和金额保持不变 |
| 拒绝入账 | 保存拒绝原因，不新增或修改任何有效费用 |

## 校验和事务

预览与提交使用同一套校验：有效币种、有限精确金额、币种小数位、费用名、日期、付款方 / 收款方与记账主体关系、目标记录归属及字段允许列表。数量和单价同时存在时核对金额；已被原流程验证的含税折扣计价可沿用，否则需补充完整依据后重新处理，不能仅跳过勾稽。

提交时在数据库中锁定账本和任务，再次校验版本及完整预览内容。账本变化或预览后修改了内容都会拒绝提交，需重新打开复审。账本、来源去重标识、版本审计、复审回执和任务复审计数在同一事务中保存；任一写入失败则整体回滚。

每个任务的每条原始待复核记录只能有一个正式决定。重复提交同一请求与预览会返回原回执，不重复入账；修改已经完成的决定会被拒绝。后续真正的业务变更应作为新材料和新任务处理。

新增、修改或确认重复后，来源归档和账本审计保留对应关系。能够取得稳定行身份时，完全相同的原件、具体行及观察值再次出现会复用人工回执、返回无变化，不让旧 OCR 值覆盖已确认的数据。缺少稳定行身份、来源或观察变化时仍按正常规则匹配，必要时再次复核。拒绝只处理当前待复核条目，不是永久屏蔽某个文件。

## 查看与导出

- **费用表**：已复审行展示正式值和人工处理结果，原始待复核标记不再计入未处理数；拒绝项可单独筛选。
- **来源文件区**：按该来源的费用复核决定展示已处理及剩余条数，全部处理后标为「费用已复核」。原始识别提示另列并默认折叠；仍有未处理费用或来源异常时展开，真正的来源异常不因费用复核而消失。
- **原始识别结果 / 原任务账本快照**：保持当时的 JSON 字节，不因人工决定改写。
- **正式复审记录 JSON**：包括复审人、原因、时间、目标、账本版本、原始观察、原有阻断问题、修改前后值及逐字段变更。
- **下载当前有效账本**：读取数据库最新状态，包含正式费用、来源身份和审计历史；不同于原任务当时的 `state.json`。

新增表 `billing_review_decisions` 保存不可覆盖的正式回执，其他表兼容原结构。首次启动会补建这张表，不清空已有账单；仍使用结构版本 1。完整备份必须包含数据库，详见 [数据库说明](database.md)。

## 当前边界

这是本机单人复审，复审人姓名由操作者填写，尚无登录身份认证、多人审批或双人复核。仅可正式处理已经提取出的待复核费用；无法解析、尚未完成、提交冲突、中断和示例任务不能据此直接入账。

复审不保证整份材料中的所有费用已经识别，也不将 OCR 或来源错误改写为成功。一个条目聚合了多条观察时，决定适用于该条目下的全部观察；如果它们实际为多笔独立费用，需要拆分材料重新处理。文件模式仍保留核对备注，正式入账需要 MySQL。

新增测试使用合成 EML 和注入模型，验证持久化、事务和网页交互；不代表新一轮真实 OCR 或模型准确率评测。复现入口为 `python -m scripts.database_checks` 和 `python -m scripts.database_browser_smoke`（后者需临时安装 Playwright）。
