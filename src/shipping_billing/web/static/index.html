BILLING DETAILS

核对与跟进

核对标记用于跟进；待复核账单不会因此自动入账。

从这里开始使用

1

上传你的业务材料

邮件上传 EML，附件会自动展开。也可以分别上传 PDF、图片、Excel 或 Word。旧版 DOC 需要本机安装 Microsoft Word。

2

填写记账公司，按需选择旧账单

记账主体用于判断应收、应付。第一次可以不传旧账单；以后点击「接续账本处理下一批」保留已处理费用及去重信息。

3

查看明细，核对需要确认的内容

新增、修改、无变化与待复核会分别标出。点击「查看依据」查看原文；缺少币种、匹配不唯一及 OCR 问题不会自动猜测为成功。

关于 PDF、图片与模型

模型配置从项目的 .env 读取，密钥不会发送给浏览器。PDF、图片及邮件图片使用指定 OCR，需要勾选临时链接或上传已有链接映射；识别失败会展示具体原因。材料中的文字会按配置发送给模型服务，启用 OCR 时相应页面会发送给指定识别服务。

处理记录保存在项目 outputs/web，上传材料保存在 data/local/web。这些本地资料不会随 Git 提交。
